### 2.1 JavaScript 速查

**状态驱动：修改只有唯一入口 `setState`，渲染只有唯一出口 `render`。**

```js
let state = { todos: [], filter: 'all' };
function setState(patch) {
  state = { ...state, ...patch };   // 唯一入口：所有修改都经过这里
  render(state);                    // 状态一变就重绘
}
// 坑：直接 state.todos.push(x) 界面不更新——React 里直接改 state 不生效是同一个原因
```

**防抖 `debounce`：停止触发后 wait 毫秒才执行（搜索输入、resize）。**

```js
function debounce(fn, wait) {
  let timer = null;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), wait);
  };
}
const onSearch = debounce((q) => fetch(`/api/search?q=${q}`), 300);
```

**节流 `throttle`：固定频率执行（滚动、鼠标移动）。**

```js
function throttle(fn, wait) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last < wait) return;
    last = now;
    fn(...args);
  };
}
window.addEventListener('scroll', throttle(onScroll, 100));
```

**事件委托：监听器挂父元素，利用冒泡统一处理动态子元素。**

```js
list.addEventListener('click', (event) => {
  const btn = event.target.closest('.delete');   // 从点击目标向上找最近匹配祖先
  if (!btn) return;
  const id = btn.closest('[data-id]').dataset.id;
  removeTodo(id);
});
```

**深拷贝用 `structuredClone`，别用 `JSON.parse(JSON.stringify())`（丢 Date/Map/Set/函数、遇循环引用抛错）。**

```js
const deep = structuredClone(obj);   // 支持 Date / Map / Set / 循环引用
// 浅拷贝：const shallow = { ...obj };
```

**并发编排：`Promise.allSettled` 部分失败不影响整体，`Promise.all` 快速失败。**

```js
const results = await Promise.allSettled(urls.map((u) => fetch(u)));
const ok = results.filter((r) => r.status === 'fulfilled').map((r) => r.value);
// 超时控制：Promise.race([fetch(u), timeout(5000)])
```

**`AbortController` 取消请求并批量解绑监听，杜绝内存泄漏。**

```js
const ac = new AbortController();
fetch('/api/search', { signal: ac.signal });
list.addEventListener('click', handler, { signal: ac.signal });
ac.abort();   // 一次性取消请求 + 解绑监听
```

**并发池 `limitConcurrency`：限制同时跑的任务数，避免一次性发几百个请求把浏览器/接口打爆。**

```js
async function limitConcurrency(tasks, limit) {
  const results = new Array(tasks.length);
  let cursor = 0;
  const workers = Array.from({ length: Math.min(limit, tasks.length) }, async () => {
    while (cursor < tasks.length) {
      const index = cursor++;
      results[index] = await tasks[index]();   // 顺序与输入一致
    }
  });
  await Promise.all(workers);
  return results;
}
const data = await limitConcurrency(urls.map((u) => () => fetch(u)), 5);   // 最多同时 5 个
```

### 2.2 TypeScript 7 速查

**TypeScript 7 关键变化（2026-09 验证）：编译器移植到 Go，检查 8~12 倍加速，`strict` 默认开启。**

| 项 | 说明 |
| --- | --- |
| 编译器 | 由 TS 移植到 **Go**（代号 Corsa），全量检查快 8~12 倍 |
| 并行 | `--checkers N`（默认 4），`--singleThreaded` 关闭并行 |
| 默认值 | `strict: true`、`target/module: esnext` |
| 已移除 | `target: es5`、AMD / UMD / SystemJS、`moduleResolution: node10` |
| API | 7.0 **无稳定编程式 API**；7.1（预计 2026-11）补齐 |
| 兼容包 | `@typescript/typescript6`（提供 `tsc6`），用 npm alias 并存 |
| 编辑器 | 语言服务基于 LSP；VS Code 用 TypeScript Native Preview 扩展 |

**最小 `tsconfig.json`（strict 默认开启，无需再写 `strict: true`）。**

```json
{
  "compilerOptions": {
    "target": "esnext",
    "module": "esnext",
    "moduleResolution": "bundler",
    "strict": true,
    "noEmit": true,
    "verbatimModuleSyntax": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}
```

**可辨识联合 + `never` 做穷尽性检查，漏处理分支编译期报错。**

```ts
type Status = { kind: 'idle' } | { kind: 'loading' } | { kind: 'error'; msg: string };
function render(s: Status): string {
  switch (s.kind) {
    case 'idle': return '待开始';
    case 'loading': return '加载中';
    case 'error': return `失败：${s.msg}`;
    default: {
      const _exhaustive: never = s;   // 新增 kind 时这里编译报错
      return _exhaustive;
    }
  }
}
```

**常用工具类型：`Partial` / `Omit` / `Pick` / `Record`。**

```ts
type User = { id: number; name: string; email: string };
type Draft = Partial<User>;                 // 全部可选
type NoEmail = Omit<User, 'email'>;         // 去掉 email
type Preview = Pick<User, 'id' | 'name'>;   // 只取两项
type ById = Record<number, User>;           // 数字键映射表
```

**`infer` 提取类型：从 Promise / 数组 / 函数签名里抠出内部类型。**

```ts
type Unwrap<T> = T extends Promise<infer U> ? U : T;
type First<T extends unknown[]> = T extends [infer H, ...unknown[]] ? H : never;
type ReturnOf<T> = T extends (...args: never[]) => infer R ? R : never;
```

### 2.3 CSS 与布局速查

**设计令牌三层：primitive（色板）→ semantic（语义）→ 组件只引用 semantic 层。**

```css
:root {
  --blue-500: oklch(0.62 0.19 255);   /* primitive：纯色板，不带语义 */
  --gray-900: oklch(0.21 0.00 0);
  --color-text: var(--gray-900);      /* semantic：组件只引用这一层 */
}
.card { color: var(--color-text); }   /* 组件绝不写死 --blue-500 */
@media (prefers-color-scheme: dark) {
  :root { --color-text: var(--gray-50); }   /* 仅翻转 semantic 层 */
}
```

**容器查询：组件按"所在容器宽度"而非视口响应（组件级响应式）。**

```css
.card-container { container-type: inline-size; }
@container (min-width: 400px) {
  .card { display: grid; grid-template-columns: 120px 1fr; }
}
```

**流式排版 `clamp()`：字号/间距随屏幕平滑变化但有上下限。**

```css
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
.hero { height: 100dvh; min-height: 100svh; }   /* dvh 避开移动端地址栏跳动 */
```

**Flex 子项文字溢出：加 `min-width: 0` 才允许收缩换行（本阶段最易忘的一行）。**

```css
.card { display: flex; }

.card .body .title {
```

**Grid 自适应宫格：`repeat(auto-fit, minmax())` 无需任何媒体查询。**

### 2.4 React 19 / 19.2 速查

**React 19.2 新增（2026-09 验证）：`use` / `useActionState` / `useOptimistic` / `useEffectEvent` / `<Activity>` 等。**

| API | 用途 |
| --- | --- |
| `use()` | 渲染中读 Promise / Context，可在条件分支调用 |
| `useActionState` | 表单 action 的状态与 pending |
| `useOptimistic` | 乐观更新（必须在 action 内调用） |
| `useFormStatus` | 子组件读取父级 form 的提交状态 |
| `ref` as prop | 函数组件不再需要 `forwardRef`；ref 回调可返回清理函数 |
| `<Activity>` | 19.2，`visible`/`hidden` 保留状态、卸载副作用 |
| `useEffectEvent` | 19.2，把"事件"从 Effect 剥离，不进依赖数组 |
| `cacheSignal` | 19.2，RSC 专用，感知 `cache()` 生命周期 |
| Performance Tracks | 19.2，DevTools 中的 React 轨道 |
| `useId` 前缀 | 19.2 起由 `:r:` 改为 `r`（快照测试需注意） |
| 安全 | RSC 相关公告已修复于 19.0.4 / 19.1.5 / 19.2.4，务必用最新补丁版 |

**Zustand 5 破坏性变更（2026-09 验证）：必须具名导入，去掉 `equalityFn`。**

| v4 写法 | v5 写法 |
| --- | --- |
| `import create from 'zustand'` | `import { create } from 'zustand'` |
| `useStore(sel, shallow)` | `useStore(useShallow(sel))` |
| `createWithEqualityFn` | `zustand/traditional` 中导入 |
| — | 要求 React 18+（基于 `useSyncExternalStore`） |

**`useState` 计数器：状态唯一来源，`UI = f(state)`。**

```tsx
import { useState } from 'react';
function Counter() {
  const [count, setCount] = useState(0);   // 状态唯一来源
  return <button onClick={() => setCount((c) => c + 1)}>点击 {count} 次</button>;
}
```

**`useActionState` + `useOptimistic`：表单乐观更新（必须在 action 内调用 `useOptimistic`）。**

```tsx
import { useActionState, useOptimistic } from 'react';
async function submit(prev: { ok: boolean }, formData: FormData) {
  const text = String(formData.get('text'));
  await fetch('/api/todos', { method: 'POST', body: JSON.stringify({ text }) });
  return { ok: true };
}
function Form() {
  const [state, action, pending] = useActionState(submit, { ok: false });
  return <form action={action}>{pending ? '提交中…' : '提交'}</form>;
}
```

**`use()` 在渲染中读 Promise / Context，可在条件分支调用（取代嵌套 hook）。**

```tsx
import { use } from 'react';
function User({ userPromise }: { userPromise: Promise<{ name: string }> }) {
  const user = use(userPromise);   // 在渲染中 await，可被 Suspense 捕获
  return <h1>{user.name}</h1>;
}
```

**`useEffectEvent`：把"事件"从 Effect 依赖数组里剥离（19.2 新增）。**

```tsx
import { useEffect, useEffectEvent } from 'react';
function Chat({ roomId }: { roomId: string }) {
  const onMessage = useEffectEvent((msg: string) => {
    console.log(`房间 ${roomId} 收到：${msg}`);   // 读 roomId 但不进依赖数组
  });
  useEffect(() => {
    const ws = connect(roomId);
    ws.on('message', onMessage);   // 不再因 roomId 变化反复重订阅
    return () => ws.close();
  }, [roomId]);
}
```

**受控组件：表单值来自状态，输入即 `setState`（避免直接读 DOM）。**

```tsx
const [value, setValue] = useState('');
<input value={value} onChange={(e) => setValue(e.target.value)} />;
```

### 2.6 Dexie 4 速查

**定义 schema 与版本迁移：`useLiveQuery` 让组件响应式订阅 IndexedDB（2026-09 验证）。**

```ts
import Dexie from 'dexie';
class AppDB extends Dexie {
  todos!: Dexie.Table<{ id: string; text: string; done: boolean }, string>;
  constructor() {
    super('app');
    this.version(1).stores({ todos: 'id, done' });        // 主键 id，索引 done
    this.version(2).stores({ todos: 'id, done, *tags' })   // 2 加多值索引 tags
      .upgrade((tx) => tx.todos.toCollection().modify((t) => { t.tags ??= []; }));
  }
}
export const db = new AppDB();
```

**`useLiveQuery` 订阅：数据变即重渲染，无手动刷新。**

```tsx
import { useLiveQuery } from 'dexie-react-hooks';

function TodoList() {
  const todos = useLiveQuery(() => db.todos.toArray(), []);   // 响应式，自动更新

  return <ul>{todos.map((t) => <li key={t.id}>{t.text}</li>)}</ul>;
}
```

**preload 用 `contextBridge` 暴露受限 API，绝不直接暴露 `ipcRenderer`。**

```ts
// preload.ts（编译为 V8 字节码以加速启动）
import { contextBridge, ipcRenderer } from 'electron';
contextBridge.exposeInMainWorld('api', {
  readFile: (p: string) => ipcRenderer.invoke('file:read', p),
  onUpdate: (cb: (v: string) => void) => {
    const listener = (_: unknown, v: string) => cb(v);
    ipcRenderer.on('app:update', listener);
    return () => ipcRenderer.removeListener('app:update', listener);   // 返回取消函数
  },
});
```

**主进程 IPC 处理：共享类型 + zod 校验 + 统一 `Result` 返回。**

```ts
import { readFileSync } from 'node:fs';
import { z } from 'zod';
import { ipcMain } from 'electron';
const ReadSchema = z.object({ path: z.string().min(1) });
ipcMain.handle('file:read', async (_e, raw) => {
  const parsed = ReadSchema.safeParse(raw);
  if (!parsed.success) return { ok: false, error: '参数非法' } as const;
  return { ok: true, data: readFileSync(parsed.data.path, 'utf8') } as const;
});
```

## 四、遇到卡住时的处理流程

1. **先读报错**：80% 的问题报错信息已经写清楚了
2. **查官方文档**（不是博客）：前端生态版本迭代快，二手内容经常过期
3. **查 changelog / GitHub issues**：如果是升级后出现的问题，大概率已有人报告
4. **最小化复现**：把问题抽到 20 行的 demo，往往抽的过程中就找到原因了
5. **设一个 30 分钟上限**：超过就记进"待解决清单"继续往前走，很多问题会在后续阶段自然解开
6. **记录**：解决后写进当阶段的 README，这是你未来最值钱的资料
