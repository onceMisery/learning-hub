# Agent 系统学习目录

> 问题来源：极客时间专栏《AI Agent 系统设计面试现场》面试脑图（85 道问题、550 个知识节点）——每个阶段用它定义「学什么、验什么」。
> 教材主线：《Agent 设计之美》（28+ 设计模式，按七认知功能 × 执行拓扑的双轴框架组织）——正面讲「该怎么设计」。
> 教材反面：《Agent 生产排雷实战》（20 讲，全是线上真实事故）——反面的工程护栏。
> 起点假设：有后端工程经验，用过至少一个大模型 API，想系统补齐 Agent 工程能力。

---

## 一、这份目录怎么用

1. **按阶段顺序推进**，每个阶段是一篇独立文档，内部按小节展开，可单独阅读、单独验收。
2. 每个小节配三条线索：**设计模式**（《设计之美》对应讲，学正面方案）→ **生产雷区**（《排雷实战》对应讲，看方案失守的样子）→ **面试追问**（脑图里的真实追问链，用来自测）。
3. 全局组织按《设计之美》的双轴框架：**认知功能轴**（感知 / 记忆 / 推理 / 行动 / 反思 / 协作 / 治理）对应阶段 01~06，**执行拓扑轴**（路由 / 循环 / 层级）的追问散布在各阶段。评审一个 Agent 时先定位「功能 × 拓扑」坐标，再谈问题——「不够稳」要能说到「推理 × 循环没有停止条件」这个粒度。
4. 每个阶段结束要能回答该阶段的**阶段终检**（最后一层追问），能讲清「为什么这样做、代价是什么、怎么验证」才算过。
5. **每篇文章的尾部固定四件**：踩坑清单 → 扩展阅读（对照 Codex 源码的实现，配示意图）→ 总结 → 思考题。先自己答思考题，再看总结。
6. 阶段 01 已有教程正文（[01-意图识别.md](./01-意图识别.md)），其余阶段的目录先行，教程按阶段逐步补齐。
