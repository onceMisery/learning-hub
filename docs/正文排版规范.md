# 正文排版规范

管的是文档页 `.lh-prose` 里的观感：标题、重点、代码、表格、提示块。
所有规则都落在 `site/src/styles/index.css` 的 `@layer components` 内，
颜色一律走 CSS 变量，两套主题各取一套值。

> 目标是"层次清晰、扫读友好"，不是"好看"。
> 技术文档的读者是来查东西的，任何装饰只要妨碍定位，就该砍掉。

---

## 一、一条铁律：全页只允许一个强调色

正文里出现的所有"有色元素"——标题竖条、重点高亮、行内代码、代码块顶光、
表格表头、提示块——**只能取自 `--prose-accent` 一族**（或提示块自带的语义色）。

| 允许 | 不允许 |
| --- | --- |
| 标题装饰、重点底色、行内代码用同一个 `--prose-accent` | 标题用蓝色、重点用黄色、行内代码用绿色 |
| 提示块用语义色（info 蓝 / warn 黄 / success 绿 / danger 红） | 正文里的普通强调也去用语义色 |

一旦引入第二个强调色，读者就再也分不清"什么重要"。

---

## 二、令牌

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--prose-fs` | `16px` | 同 | 正文字号。中文长文的下限，不要再调小 |
| `--prose-lh` | `1.85` | 同 | 正文行高。中文比英文需要更大行距 |
| `--prose-flow` | `1.1em` | 同 | 块与块之间的基础间距 |
| `--prose-accent` | `#7c9cff` | `#4f6bed` | 正文强调色（唯一的强调色） |
| `--prose-em-bg` | `rgba(124,156,255,.24)` | `rgba(79,107,237,.16)` | 重点文字的"荧光笔"底色 |
| `--prose-inline-bg` | `rgba(124,156,255,.10)` | `rgba(79,107,237,.08)` | 行内代码底色 |
| `--prose-inline-fg` | `#a9bcff` | `#3a51c8` | 行内代码文字色 |
| `--prose-quote-bg` | `rgba(124,156,255,.06)` | `rgba(79,107,237,.05)` | 引用块底色 |
| `--prose-flow-rule` | 白 11.5% 两端渐隐 | 深蓝 14% 两端渐隐 | **段落之间的分割线**（见第六节） |
| `--content-max` | `800px` | 同 | 正文列宽（中文一行 38~42 字） |

浅色主题一律**降低饱和度**而不是提高亮度：纸白底上过艳的颜色会"跳"出来，
反而压过正文。

## 三、标题层级

三层表达，装饰量与层级成反比——越深的标题越安静。

| 层级 | 字号 | 装饰 | 意图 |
| --- | --- | --- | --- |
| h2 | `1.5em` | 上方**向右渐隐**的分隔线 + 左侧 3px 强调色竖条 | 章节边界，扫读时的锚点 |
| h3 | `1.17em` | 左侧 2px 强调色竖条（更细更矮） | 小节，与 h2 同一视觉语言但更轻 |
| h4 | `1.04em` | 无装饰，仅降色为 `--text-2` | 不应抢注意力 |

实现要点：

- 竖条用 `::after` **绝对定位**，只伴随首行（`height: 1.02em`），
  不要用 `border-left` —— 多行标题会拉出一条贯穿全标题的大色块，显得很笨。
- 分隔线用 `::before` + `linear-gradient(90deg, var(--border-strong), transparent 72%)`,
  比 1px 实线更"轻"，不会把长文切成一段段。
- 首个子元素（`> h2:first-child`）必须去掉上边距与分隔线，否则页面顶部会多出一条横线。
- `scroll-margin-top` 保留在标题上（TOC 跳转时不被固定顶栏盖住）。

## 四、重点与强调

| 元素 | 处理 | 原因 |
| --- | --- | --- |
| `strong` | 字重 650 + **下半部荧光笔底色**（`linear-gradient(transparent 58%, var(--prose-em-bg) 58%)`） | 纯加粗在中文字体里差别太小；长文扫读时颜色比字重更抓眼 |
| `strong` 内嵌行内代码 | 去掉行内代码自己的底色与边框 | 两层底色叠加会脏 |
| `em` | 斜体 + 略偏强调色 | 中文没有真斜体，靠颜色补足 |
| `a` | `text-decoration: underline` + `text-underline-offset: 3px` + 半透明下划线，hover 时下划线变实、加淡底 | 链接在正文里必须始终"可识别"，不能只靠颜色 |
| `mark`（搜索命中） | 保持 `--mark` | 与"重点"区分开：这是系统高亮，不是作者强调 |

## 五、代码

**行内代码**：与强调色同源——底色 `--prose-inline-bg`、文字 `--prose-inline-fg`、
边框 `color-mix(in srgb, var(--prose-accent) 22%, transparent)`。
这样"这是一个标识符"和"这是重点"是同一套色彩系统里的两种强度。

**代码块**（`.lh-code`）：

- 顶边一道**强调色渐隐高光**（`::before`），作为代码块的身份标识
- 极淡投影 `0 12px 32px -26px rgba(0,0,0,.65)`，把块从正文里"托"起来；深色下几乎不可见
- 标题栏的语言名用强调色 + `letter-spacing: .07em` + 字重 600

**多语言对照块**（`.lh-langtabs`）与代码块共用同一套顶光线与投影；
选中标签的边框色用 `color-mix(in srgb, var(--prose-accent) 48%, transparent)`。

高亮本身仍由 Shiki 在构建期完成（`.shiki` / `--shiki-dark` / `--shiki-light`），
**不要**在 CSS 里覆盖 token 颜色。

## 六、表格 / 引用 / 分隔线

- 表头：`color-mix(in srgb, var(--prose-accent) 9%, var(--surface-2))`，下边框用强调色 26% 混合
- 斑马纹：偶数行 `color-mix(in srgb, var(--surface-2) 55%, transparent)`，**对比要极低**，
  只为长表格"不串行"，不制造噪音
- 行 hover：强调色 8% 淡底
- 引用块：左侧 3px 强调色半透明竖条 + 圆角 + 淡底，与 Callout 区分开（Callout 有图标与实色条）

### 分割线：三种强度，一套语言

正文里一共只有三类横线，**全部用中性色、全部两端渐隐**，
靠强度与长度拉开层级，绝不引入第二种颜色：

| 级别 | 出现位置 | 强度 | 实现 |
| --- | --- | --- | --- |
| 强 | `hr`（作者显式分节） | `--border-strong` 全强度 | `linear-gradient(90deg, transparent, var(--border-strong), transparent)` |
| 中 | `h2` 上方（章节边界） | `--border-strong`，向右渐隐 | `::before` + `linear-gradient(90deg, var(--border-strong), transparent 72%)` |
| 弱 | **相邻正文块之间** | `--prose-flow-rule`（约七成强度） | `::before` + `linear-gradient(90deg, transparent, C 12%, C 88%, transparent)` |

**段落分割线的规则：**

- 触发条件：`.lh-prose` 的**相邻直接子元素**都是「正文块」，即
  `p` / `ul` / `ol` / `blockquote` 的任意组合。
- 位置：`top: calc(var(--prose-flow) * -0.675)`，正好落在两块的**正中间**；
  配套把 `margin-top` 放大到 `calc(var(--prose-flow) * 1.35)`，
  线才有地方"待"，不会贴住上下文字。
- **不画线的位置**（由选择器天然排除，不需要额外兜底）：
  - 标题——h2 自带上方分隔线，h3/h4 靠强调色竖条起段；
  - 代码块 / 多语言对照 / 提示块 / 图片——自带边框或留白，边界已经清楚；
  - 表格——`.lh-table-wrap` 是 `overflow` 容器，会裁掉伪元素，且它本身就有边框；
  - 提示块内部的嵌套正文——`.lh-prose--nested` 上关掉，盒中盒再画线会变脏。
- 竖条/框线一律不参与：分割线是"骨架"，不是内容，**不允许使用 `--prose-accent`**。

---

## 七、提示块（Callout）

- 左侧 3px **实色**语义色条：整页提示块在视觉上形成一条可扫读的"警示轨"
- 图标加圆形淡底（同色 16%），比裸图标更容易被看见
- 正文 15px / 行高 1.78，比正文略小但行距一致

---

## 八、改动前的自检

- [ ] 没有引入第二个强调色（分隔线用的是中性色 `--prose-flow-rule`，不是 `--prose-accent`）
- [ ] h4 及以上没有新增装饰
- [ ] 新增样式写在 `@layer components` 内（裸写会压掉 Tailwind 工具类）
- [ ] 深浅两套主题都看过（浅色下饱和度是否过高）
- [ ] 正文列宽仍 ≤ 800px
- [ ] 分割线改过后，确认这三处仍然"无线"：标题上方、代码块/多语言对照上方、提示块内部
- [ ] `pnpm typecheck` + `smoke` 通过，并用 Playwright 截两套主题的图确认
