# 部署说明

站点有两条部署线：**GitHub Pages（主）** 与 **Vercel（备用）**。两者吃同一份构建产物，
但 base 路径不同——这是最容易踩的一处差异。

## 一、构建产物

```bash
cd site
pnpm install
pnpm build      # 内容校验 → 内容生成 → tsc --noEmit → vite build
```

产物在 `site/dist`。注意 `site/public/content/` 是**内容生成物**，不是产物目录，
Output Directory 选它只会得到一个空站点。

## 二、GitHub Pages（主）

- 工作流：`.github/workflows/deploy.yml`，push 到 `main` 触发，构建时注入
  `SITE_BASE=/learning-hub/`（子路径部署，资源前缀全靠它）。
- 仓库需为 **public**：Pages 只对私有仓库收费，公开仓库在 Free 计划下免费。
- Settings → Pages → Source 选 **GitHub Actions**。
- 额度：站点 ≤ 1GB、带宽 100GB/月（软限）。用自定义 Actions 发布时，
  不受「10 次构建/小时」的软限制——我们正是这种方式。

## 三、Vercel（备用）

`vercel.json` 放在**仓库根**，Root Directory 也保持仓库根：

| 字段 | 值 | 原因 |
|---|---|---|
| `framework` | `null` | 关掉 Vite 预设，否则 Vercel 不读我们的命令 |
| `installCommand` / `buildCommand` | `cd site && ...` | 站点在子目录 |
| `outputDirectory` | `site/dist` | 见上文 |
| `rewrites` | `/(.*) → /index.html` | 站点用 BrowserRouter，缺了它深链会 404 |

三个已踩过的坑：

1. **`vercel.json` 放在 `site/` 且 Root Directory 设为 `site` 时，Vercel 不读它**，
   会按 Vite 预设默认跑 `vite build`，报 `vite: command not found`（exit 127）。
2. **不要在 Vercel 上设置 `SITE_BASE`**。Pages 走子路径需要它，Vercel 部署在根域名，
   必须用默认的 `/`，否则静态资源全部 404。
3. **pnpm 版本**：见下节。

### ERR_INVALID_THIS / ERR_PNPM_META_FETCH_FAIL

Vercel 容器里的默认 pnpm 偏旧，在新版 Node 上请求 registry 会炸：

```
WARN  GET https://registry.npmjs.org/react-router-dom error (ERR_INVALID_THIS). Will retry in 10 seconds.
ERR_PNPM_META_FETCH_FAIL  GET https://registry.npmjs.org/@types%2Fjsdom: Value of "this" must be of type URLSearchParams
Error: Command "cd site && pnpm install" exited with 1
```

这是 JS 层的类型错误，**不是网络问题**，重试也没用。解法是在命令里钉死 pnpm 版本：

```
npx --yes pnpm@10.32.1 install --frozen-lockfile
```

用 `npx` 而不是 corepack：corepack 依赖全局目录写权限，而且要在 Vercel 后台开
`ENABLE_EXPERIMENTAL_COREPACK`。仓库根没有 `package.json` 时，Vercel 本来也不会
去解析 `packageManager` 字段。

升级 pnpm 时的顺序：本地升级 → 改 `vercel.json` 里的版本号 → 提交 `pnpm-lock.yaml`。
版本号与本地 `pnpm --version` 保持一致，构建行为才对得上。

## 四、上线前自检

```bash
cd site
pnpm check      # 配置与断链
pnpm paths      # 本机绝对路径泄露
pnpm build      # 含 typecheck
pnpm smoke      # 渲染冒烟
```

四条全绿再推 `main`。
