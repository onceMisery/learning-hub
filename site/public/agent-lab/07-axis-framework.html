双轴坐标系：给 Agent 系统一个唯一地址

「我们用了 agent workflow」这句话的信息量是零——没人知道你在解哪类问题，也没知道你会怎么失败。换成坐标系：纵轴七脉认知功能，横轴六式执行拓扑，完整名字必须写成「功能 × 拓扑」。这页课的矩阵可以直接点击，动画同时演示评审时怎么看图，支持自动运转和分步点击两种模式。

① 表象观察→ ② 静态分解→ ③ 动态分析→ ④ 动静融合→ ⑤ 环境场景→ ⑥ 复盘自测
红点 = 关键缺口坐标 琥珀 = 当前游标 / 扫描格 灰格 = 刻意留空 / 待定位
相位 -- 阶段 -- 关键量 --
第二视图 · 评审扫览 · 行/列覆盖与可靠性（与主图同步）
读法：左图看扫描覆盖到第几行第几列，右图看链路变长时可靠性如何乘性衰减。
速度1× 演示速度 ≈ 1 轮扫览 / 6.4 秒
自动运转模式 点下方步骤点可切换到分步演示，随你点击定格；也可以直接点矩阵里的格子。

相位口径：0° = 坐标系总览；720° = 扫览结束回到中心。七脉 60–140°、六式 140–220°、四个坐标 220–540°；副图与主图同相位。

1

表象观察：先把它当黑盒

第一步不拆机器，只看它对外表现出什么行为。

「对事物的观察包括了静态结构 + 动态生命周期 + 环境场景三个方面的内容。」

从外部看，这张坐标系做的事只有一件：把一句形容词翻译成一个能被反驳的工程判断。「感觉不够稳」没法执行；「推理 × 循环缺停止条件」是个能答的问题——「那停止条件你写在哪」。输入是任何 Agent 系统，输出是它的唯一地址、错误传播路径与升级路线。

一个 Agent 系统（含含糊糊的介绍）→ 双轴定位（黑盒）→ 功能 × 拓扑坐标（主产物） 缺口清单 / v1→v2 路线（副产物）

黑盒观察的结论：这是一台讨论权的分发机器——有了共同语言，大家才吵得更准。带着这个结论，现在打开黑盒。

2

静态分解：它由什么组成

打开黑盒，沿空间维度拆解。点部件卡片，动画中对应部分会亮成琥珀色。

「它由什么构成？核心方法是分解、分类、结构化——分解需符合 MECE 法则，同层必须粒度一致。」

双轴框架本身（作为一台「定位机器」）可按功能分成四组：

纵轴组 —— 负责「它在解哪类问题」
横轴组 —— 负责「能力与信息怎么流动」
操作组 —— 负责「十分钟出第一版架构」
公理组 —— 负责「别炫技」

静态分解只回答了「有什么」。评审现场怎么用这四组部件定位一个系统？必须切换到时间维度——下一节。

3

动态分析：它如何运转

盯住那个琥珀色游标。用动画下方的 9 个步骤点逐帧看完一次评审式扫览。

「它如何演变与运作？关注时间轴上的发展规律、行为模式和内部流程。核心方法是流程分析、行为追溯。」

操作：点击动画下方步骤条上的圆点（或「下一步」按钮），画面会定格在对应扫览阶段；也可以直接点矩阵里任意格子，右侧详情卡会显示该坐标的工程后果（再点一次取消选择）。建议完整走两遍：第一遍只看游标扫过哪几行哪几列，第二遍同时读右侧详情卡。

阶段时刻游标位置右侧详情这一步在干什么

两个容易错过、但值得在分步模式里细看的点：① 四个红色关键坐标都是「缺约束」而不是「缺能力」——评审的价值在指出空格，不在罗列名词；② 第 ⑧ 阶段三步卡的产出是最小可行的稳定组合，第一版就塞满矩阵的人，一般是不舍得删。

4

动静融合：部件如何协同出「可讨论的架构」

把第 2 节的「结构」和第 3 节的「流程」叠在一起——这才是理解的完成态。

「动静融合的关键是建立映射：将组成部件与操作步骤一一对应，理解各部件如何协同产生外在行为。系统 = 元素 + 连接 + 目标。」

映射表：每个部件在每个阶段里承担什么角色。竖着看是一个阶段的全体协同，横着看是一个部件的完整职责。

部件 ＼ 阶段① 总览② 七脉③ 六式④-⑦ 坐标⑧ 三步卡⑨ 公理
七脉（纵轴）行存在逐行亮 + 管什么列扫过的行提供问题类型被打徽标缺脉即失控
六式（横轴）列存在行扫过的列逐列亮 + 错误怎么跑提供错误路径判主拓扑选拓扑即选错误
关键坐标红点预置——闪红 + 缺口SELECT 的输入约束优先项
三步卡———缺口清单逐格点亮产出最小组合
Compound Error————控制模式数 3~7四问拷问

点题一句：「评审五分钟后能吵起来」这个外在行为，不是任何一个部件的属性，而是「七脉 × 六式 × 缺口句式」整体协同涌现的。「推理 × 循环没有停止条件」之所以是个好句子，是因为功能、拓扑、约束三样一齐摆出来，对方立刻能反驳你也能补你。对称设计在另一侧：刻意留空也要给理由——没做长期记忆，答「不需要」和答「忘了」，是两种完全不同的可信度。

5

环境场景：它依赖什么才能工作

主体之外，还有一圈支撑系统。

「对事物的认识 = 空间属性 + 时间属性 + 环境属性（外在关系和依赖）。」
教材双轴《Agent 设计之美》用七认知功能 × 执行拓扑组织 28+ 设计模式——坐标系不是发明，是对一套真实模式库的编目。
事故库《生产排雷实战》20 讲线上真实事故。每个缺口句式最好都对照一次失守现场，才知道约束防的是什么。
源码证据逆向五步法：主循环、七脉归因、主动丢七成、落矩阵、回到行号。「很重治理」后面得跟着三个能翻开看的位置。
测试策略错误传播路径直接带出测试重点：级联型测中间格式，误派型测分类器，误复合型测停止与评估信号。
选型五问主循环清楚吗 / 上下文是显式机制吗 / 工具有结构约束吗 / 状态能恢复回放吗 / 高风险边界在哪——拿去问别人，每问一句对方就得给机制。
叙事纪律三问（发现什么难题、设计了什么机制、改善到什么程度）+ 十问自检。数据口径说不清的那句就别写。

动画里的定位机器能转起来，前提是这六个系统在「环境」里就位。拆掉任何一个，外在行为立即消失——尤其是事故库和源码证据：拆掉它们，坐标系立刻退化成一张好看但无从反驳的分类表。

6

复盘自测：学习-实践-复盘的闭环

用自己的话能讲清楚，才算真的懂。先答题，再对照解析。

一页带走

模型负责花钱，结构负责管账；没有唯一地址，就没有可讨论的工程后果。

· 方法：表象（讨论权分发机器）→ 结构（四组部件）→ 流程（九阶段）→ 融合（可讨论性是涌现属性）。

· 结构：七脉（资源预算）× 六式（错误移动）+ 三步卡 + Compound Error 公理 + 刻意留空。

· 行为：先扫行再扫列，四个红色坐标全是「缺约束」；ASSESS → ROUTE → SELECT 产出最小稳定组合。

· 协同：功能 × 拓扑 × 缺口句式三样齐摆，评审才吵得准；空格也要给理由。

· 边界与简化：42 格不逐一展开，只标四个常见缺口；Compound Error 假设单步成功率恒为 0.95。
