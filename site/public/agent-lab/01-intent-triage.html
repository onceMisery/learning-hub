意图分诊台：Agent 的第一道控制决策

意图识别不是「调一次大模型分类」，而是控制平面的第一个决策：三层级联便宜的先上，置信度闸门决定采纳 / 澄清 / 抬层，最终产出一份驱动下游一切决策的控制契约。这页课按「表象 → 结构 → 流程 → 融合」的认知链组织，动画支持自动运转和分步点击两种模式。

① 表象观察→ ② 静态分解→ ③ 动态分析→ ④ 动静融合→ ⑤ 环境场景→ ⑥ 复盘自测
琥珀 = 当前令牌 / 采纳 绿 = 过闸采纳 红 = 抬层 / 澄清区 灰虚线 = 未命中 / 出口
相位 -- 阶段 -- 关键量 --
第二视图 · 闸门裁决状态 · 置信度随相位（与主图同步）
读法：先看指针落在哪一区，再看接口是否点亮。副图与主图、步骤条共用同一相位；分步定格时一起冻结。
速度1× 演示速度 ≈ 1 轮 / 5 秒
自动运转模式 点下方步骤点可切换到分步演示，随你点击定格。

相位口径：0° = 用户输入进场；720° = 契约分发下游。规则层 140°、L2 230°、L3 368°、闸门 390°；副图与主图同相位。

1

表象观察：先把它当黑盒

第一步不拆机器，只看它对外表现出什么行为。

「对事物的观察包括了静态结构 + 动态生命周期 + 环境场景三个方面的内容。」

从外部看，意图识别做的事只有一件：一句用户话进来，一份控制契约出去。它不回答用户的问题、不调用工具、不生成方案——那都是主循环的事。它只决定「接下来该怎么想、加载什么上下文、调用什么工具、进入哪个业务流程」。

用户输入（含失真）→ 意图识别（黑盒）→ IntentResult 契约（主产物） 追问 / 拒识（副产物）

黑盒观察的结论：这是一台控制信号压缩装置——模糊自然语言进，离散可执行的控制决策出。带着这个结论，现在打开黑盒。

2

静态分解：它由什么组成

打开黑盒，沿空间维度拆解。点部件卡片，动画中对应部分会亮成琥珀色。

「它由什么构成？核心方法是分解、分类、结构化——分解需符合 MECE 法则，同层必须粒度一致。」

意图分诊台可按功能分成五组，互不遗漏、互不重叠：

输入组 —— 负责「把话洗干净」
级联组 —— 负责「便宜的先上」
闸门组 —— 负责「裁决怎么走」
契约组 —— 负责「输出可执行、可审计」
出口组 —— 负责「契约落地」

静态分解只回答了「有什么」。一次输入怎样穿过三级层、怎样被闸门裁决？必须切换到时间维度——下一节。

3

动态分析：它如何运转

盯住那个琥珀色令牌。用动画下方的 9 个步骤点逐帧走完一次完整分诊。

「它如何演变与运作？关注时间轴上的发展规律、行为模式和内部流程。核心方法是流程分析、行为追溯。」

操作：点击动画下方步骤条上的圆点（或「下一步」按钮），画面会定格在对应时刻。建议完整走两遍：第一遍只看令牌走哪条路，第二遍同时看右侧闸门指针和置信度读数。

阶段时刻规则层轻量层深度层这一步在干什么
① 输入进场0°–70°———用户请求进入输入区，准备接受规范化
② 规范化70°–140°———六类失真处理完，句子才算可判定
③ L1 判定140°–230°未命中——能用 if 解决的意图不用 token；本例是新意图，规则层沉默
④ L2 判定230°–330°—0.55 低置信—要跨轮继承槽位，轻量模型啃不动，抬层
⑤ L3 判定330°–390°——0.88 + reason深度推理交出思考痕迹，置信度过线
⑥ 闸门裁决390°–480°≥0.85 → 采纳三区间决定采纳 / 澄清 / 抬层
⑦ 契约生成480°–560°8 字段逐一点亮reason 在最前，「想」发生在「拍板」之前
⑧ 校验四查560°–640°枚举 / 白名单 / 重算 / 归一能用代码确定性算出的，绝不让模型猜
⑨ 分发下游640°–720°换整个运行时Spec、上下文、工具、审批门，一张契约驱动全部

两个容易错过、但值得在分步模式里细看的点：① 「继续」「好的」这类延续性输入在 L1 就结束了——零成本零延迟，丢给大模型反而偶尔误判；② L3 的 0.88 是模型自评分，它不是校准过的概率，所以闸门阈值 + 仲裁要一起吃规则命中、向量相似度、上轮意图稳定性这些算得出来的信号。

4

动静融合：部件如何协同出「控制契约」

把第 2 节的「结构」和第 3 节的「流程」叠在一起——这才是理解的完成态。

「动静融合的关键是建立映射：将组成部件与操作步骤一一对应，理解各部件如何协同产生外在行为。系统 = 元素 + 连接 + 目标。」

第一张映射表：每个部件在每个阶段里承担什么角色。读法：竖着看是一个阶段的全体协同，横着看是一个部件的完整职责。

部件 ＼ 阶段① 输入② 规范化③ L1④ L2⑤ L3⑥ 闸门⑦⑧ 契约校验⑨ 分发
输入区接收交付原文——————
规范化—六类失真清洗——————
L1 规则层——未命中 · 沉默—————
L2 轻量层———0.55 · 发表意见————
L3 深度层————0.88 + reason———
置信度闸门—————采纳——

点题一句：「意图识别要能独立评估、独立灰度、独立回滚」这个外在特性，不是任何一个部件的属性，而是「级联 + 闸门 + 契约 + 校验」整体协同涌现的。拆开看，每一层都只是便宜或贵一点的分类器；合起来，它才成为控制平面上一个可审计、可回滚的决策点。同时两个出口（unclear / unsupported）是这套协同的保险丝——没有它们，模型只能硬选一个最像的意图，然后一本正经地胡说八道。

5

环境场景：它依赖什么才能工作

主体之外，还有一圈支撑系统。

「对事物的认识 = 空间属性 + 时间属性 + 环境属性（外在关系和依赖）。」
输入规范化服务上游把六类失真洗完，识别层才拿到「可判定语义」；拿用户原话直接匹正则，命中率会惨不忍睹。
意图表配置IntentSpec 写成数据而非 Prompt 字符串：能被校验、能被裁剪、能被测试，逐条与测试集对账。
多轮状态存储继承、保守切换、槽位合并、约束累加——第二轮准确率断崖下跌，绝大多数是这里稀烂。
测试集与评估标准 / 口语 / 缺失 / 拒识 / 易混淆五类样本，Top-K、分意图、误拒漏拒率——没有它，一切优化都是玄学。
埋点与留痕每层候选集、置信度、是否下推、最终采纳及原因、Prompt 与意图表版本——三个月后救你命的东西。
降级与自纠错链自纠错 ≤ 2 次、结构化错误摘要回喂、核心字段无效则挂起转人工——绝不一抛异常就停摆。

动画里的分诊台能转起来，前提是这六个系统在「环境」里就位。拆掉任何一个，外在行为立即消失——这也是分析任何系统时要画出边界和依赖的原因。

6

复盘自测：学习-实践-复盘的闭环

用自己的话能讲清楚，才算真的懂。先答题，再对照解析。

一页带走

便宜的先上，闸门三区控升降；契约驱动下游，输出永不当可信。

· 方法：表象（控制信号压缩）→ 结构（五组部件）→ 流程（九阶段）→ 融合（控制契约是涌现属性）。

· 结构：输入规范化 + 三层级联 + 置信度闸门 + IntentResult 契约 + 校验层 + 下游运行时。

· 行为：规则层兜确定性输入，轻量层扛流量，深度层啃硬骨头并交出 reason；闸门三区间决定采纳 / 澄清 / 抬层。

· 协同：独立评估、灰度、回滚的能力不属于任何单层，属于整体；unclear / unsupported 两个出口是保险丝。

· 边界与简化：本例按一次成功分诊演示，未展开「澄清→补槽→再判」的回环；0.85 / 0.60 是示意阈值，真实值需用测试集分意图校准。
