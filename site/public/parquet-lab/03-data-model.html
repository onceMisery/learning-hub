表象观察：8 种物理类型，装下一棵 JSON

字符串、小数、时间戳、数组、地理点，最后都落到几种字节布局上。

「先分清“存储类型”和“语义类型”，再谈嵌套。」

Parquet 的物理类型只有 BOOLEAN、INT32、INT64、INT96、FLOAT、DOUBLE、BYTE_ARRAY、FIXED_LEN_BYTE_ARRAY。字符串是 UTF-8 字节，小数是未缩放整数，时间是整数计数；语义由 LogicalType 注解说明。

字节+LogicalType→字符串 / 小数 / 时间 / 地理+def / rep→嵌套结构

LIST/MAP 的排序是未定义的；不要拿 min/max 去裁它们，页索引也只在能定义顺序的列上可靠。

5

环境场景：地理类型与外部语义

GEOMETRY / GEOGRAPHY 不是“多一个类型”，而是多一整套坐标语义。

「环境属性 = 坐标系 + 轴顺序 + 边插值 + 统计口径。」
CRS默认 OGC:CRS84（经度/纬度，WGS84）；也可用 EPSG、PROJJSON、srid。
轴顺序WKB 和 bbox 永远是 (x,y)，x=经度/easting，覆盖 CRS 自己的轴顺序。
边插值GEOMETRY 平面；GEOGRAPHY 要指定 SPHERICAL / VINCENTY / KARNEY 等。
bboxx/y 必有，z/m 可选；NaN/null 跳过；跨反子午线时 xmin 可大于 xmax。
geospatial_typesWKB 类型码列表；空列表表示未知；值必须唯一。
统计边界只能用 bbox 做空间相交；几何值本身没有统一排序。
6

复盘自测

能说清“def 是层数、rep 是层号”，才算真的懂 Dremel。

一页带走

def 说停在哪层，rep 说从哪层重复；NULL 只活在 level 里。

· 物理类型只有 8 种，语义靠 LogicalType；ConvertedType 是旧表示，writer 要双写。

· LIST/MAP 的 3 层结构区分“容器不存在 / 容器为空 / 元素为空”。

· Dremel 用 def/rep 把树压成线性流；NULL 不占值区。

· 排序规则由逻辑类型决定；LIST/MAP/GEOMETRY 没有统一排序，不能拿 min/max 裁。

· 地理类型用 WKB + bbox；跨反子午线要按环绕区间判断。
